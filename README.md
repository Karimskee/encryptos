# 🔐 Encryptos

**An academic encryption project for the Faculty of Computers & Artificial Intelligence, University of Sadat City — Information Security course.**

This project focuses on cryptographic techniques and secure data handling as part of an information security curriculum. It was developed using **GDScript** and is structured as a Godot Engine project.

## 📌 Overview

Encryptos is an educational project that demonstrates core concepts in encryption and decryption. It was created as part of coursework to help improve understanding of principles such as:

- Symmetric and/or asymmetric encryption
- Encryption workflows in code
- Data protection best practices  

🛠️ Built with:
- **GDScript** (Godot Engine)
- Project assets and example encryption logic

## 🚀 Features (Example)

- 🔐 Encrypts text or files with a user-defined key  
- 🔓 Decrypts encrypted content back to original form  
- 📄 Demonstrates secure handling of keys and messages  
- 📊 Shows encryption results and statistics
